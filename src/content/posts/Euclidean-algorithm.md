# 유클리드 호제법
최대공약수를 구하기 위한 대표적인 알고리즘이다.  
두 수의 최대공약수가, 큰 수를 작은 수와의 차이로 대체해도 변하지 않는다는 원리에 기반한다.  
2개의 자연수 a, b에 대해 a ÷ b의 나머지를 r이라고 하자. a, b의 최대공약수는 b와 r의 최대공약수와 같다.  
$$gcd(a, b) == gcd(b, r)$$ 이 성질에 따라 b ÷ r의 나머지 r'을 다시 구하고, r ÷ r'의 나머지를 구하는 과정을 반복하여 나머지가 0이 되었을 때 나누는 수가 a, b의 최대 공약수가 된다.

# 확장 유클리드 호제법 
:::note
- ≡ : 값이 완전 같은 건 아니지만, 어떤 기준으로 보면 동일(같은 위치, 가치)하다.
- $mod\:n$ : 숫자가 n에 도달하면 다시 0으로 리셋
- inverse(영원) : 일반적으로 곱해서 1이 되게 만드는 수. 예시로 5의 역원은 $\frac{1}{5}$ 이다.  mod n 세상에서는 정수만 존재하므로 mod n 에서 x의 역원 y는 $xy = 1(mod\:n)$ 즉, x에 y를 곱하고 n으로 나누었을 때 나머지가 1이 되는 y라는 뜻이다. 
::: 

$xy ≡ 1\:mod\:26$ 은 x 

x가 mod n 에서 역원을 가지려면 gcd(x n) = 1 이어야 한다. x, n의 최대공약수가 1 (x n이 서로소)이어야 역원이 존재하기 때문이다. 

예시로 inverse of 15 mod 26 을 구해보자. 이는 15의 역원을 mod 26 체계에서 구하라는 뜻이다.  
역원이 존재하기 위해서는 gcd(15, 26) = 1을 만족해야 한다.  

0단계 부터 시작한다고 하자. i단계에서 얻은 몫을 $q_{i}$, 각 단계를 수행하면서 보조수 $p_{i}$ 를 계산한다.  
첫 두단계의 보조수는 $p_{0} = 0, p_{1} = 1$ 로 주어진다. 나머지 $p_{i}$ 값은 $p_{i} = p_{i - 2} - p_{i - 1}q_{i - 2}\:mod\:n$ 으로 계산한다.$p_{i}$의 계산은 유클리드 호제 계산 마지막 단계의 다음 단계까지 계산한다.
